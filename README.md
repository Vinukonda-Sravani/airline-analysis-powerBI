# ✈️ Airline Route & Cost Analysis Dashboard

## 📌 Overview
This project analyzes airline operational and financial performance using Power BI.  
The goal was to move beyond static reporting and build a dashboard that supports data-driven decision making.

---

## 🎯 Objectives
- Analyze aircraft demand and route performance  
- Compare revenue and cost across demand conditions  
- Identify profitability drivers  
- Provide actionable business insights  

---

## 🛠 Tools Used
- Power BI  
- DAX (Data Analysis Expressions)  
- Data Cleaning & Transformation  

---

## 📊 Key Insights
- Boeing 777-300ER generates the highest revenue  
- Weekend flights generate higher revenue despite fewer flights  
- High-capacity aircraft perform better during peak demand  
- Profitability varies significantly across routes  

---

## 💡 Business Recommendation
Airlines should prioritize high-capacity aircraft on high-demand routes to maximize revenue efficiency and profitability.

---

## 🚀 What I Learned
- Translating data into business insights  
- Designing interactive dashboards  
- Using DAX for dynamic KPIs
